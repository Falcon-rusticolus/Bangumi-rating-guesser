# 动画猜评分

一款基于 Bangumi 动画数据的单页竞猜小游戏。每局 10 轮，根据标题、封面、制作公司与放送开始日期猜测该动画的 Bangumi 评分。

## 启动方式

直接双击 `index.html`，用浏览器打开即可。页面完全离线运行，无需安装依赖或启动服务器。

## 数据

- 数据来自 `data.js`，选择了bangumi上评分人数多于5000人的所有动画，共 774 部。
- 封面保存在 `assets/covers/` 中，文件名对应作品排名。

## 计分方式

设猜测评分与真实评分的绝对差为 `x`，单轮得分 `y = f(x)`：

```text
f(x) = 10 − 5x,          0 ≤ x < 1.5
f(x) = 5 − (5/3)x,       1.5 ≤ x < 3
f(x) = 0,                x ≥ 3
```

单轮最高 10 分，10 轮总分最高 100 分。每轮得分保留两位小数。
